# 🏃‍♂️ Ihlen Sosiale Løpeklubb Web App

Official website for Ihlen Sosiale Løpeklubb – a social running club focused on community, consistency, and shared miles.

🌐 https://ihlenslk.no

# Overview

This project is a modern web application built with Next.js, designed to provide:

Club information and updates
Integration with Strava (segments and club data)
A fast and responsive user experience

# Tech Stack

Framework: Next.js, Typescript, Tailwind, Neon, PostgreSQL
CMS: Sanity
API Integration: Strava API, intern api layers
Deployment: Vercel

# 🚀 Getting Started
1. Clone the repository
git clone https://github.com/your-repo/ihlenslk-web.git
cd ihlenslk-web
2. Install dependencies
npm install
## or
yarn install
3. Configure environment variables

Create a .env.local file in the root of the project:

NEXT_PUBLIC_SANITY_PROJECT_ID=
NEXT_PUBLIC_SANITY_DATASET=
STRAVA_SEGMENT_ID_1=
STRAVA_SEGMENT_ID_2=
STRAVA_SEGMENT_ID_3=
STRAVA_CLUB_ID=
STRAVA_CLIENT_ID=
STRAVA_CLIENT_SECRET=
STRAVA_REFRESH_TOKEN=
